功能

金流、疊層與市集

核心擁有帳本。付款外掛只負責開單與驗證通知，通過後才由核心入帳。疊層用權杖連上 WebSocket，不使用登入 Cookie。

金流 疊層 外掛市集 架構 技術 安全

官方金流，一種方式一個外掛

金流只有官方索引點名的方式可以安裝。名字以 official. 開頭並不夠。社群外掛不能成為付款提供者。

外掛 付款方式
official.ecpay 綠界信用卡（一次付清）
official.ecpay-atm 綠界 ATM 虛擬帳號
official.ecpay-cvs 綠界超商代碼
official.ecpay-barcode 綠界超商條碼
official.opay 歐付寶信用卡（一次付清）
official.opay-atm 歐付寶 ATM 虛擬帳號
official.opay-cvs 歐付寶超商代碼

歐付寶超商條碼的程式留在版本庫，但尚未列入官方索引，這個版本不會載入，贊助頁也不會出現。

贊助頁看到什麼

只列出已啟用、而且必填欄位都已設定的方式。觀眾填顯示名稱、金額與留言。金額是整數新台幣，預設下限 30、上限 20000。

什麼時候才入帳

核心只在金額等於伺服器訂單、且廠商交易編號一致時入帳。ATM 與超商取號只把訂單改成待繳費，不入帳、不送提醒。

帳本狀態有待付款、待繳費、已付款、已過期、待人工處理、失敗。設定步驟、回呼網址與測試站差別見 綠界與歐付寶。

提醒、目標、跑馬燈、聊天

四者共用同一條 OBS 網址、同一張畫布。重新產生網址後，舊的疊層權杖立即失效。

贊助提醒

可調範本、顏色、進場與退場動畫、顯示時間與提示音。範本可用 {name}、{amount}、{message}、{currency}。畫面上的結果是純文字，不會變成 HTML。

目標進度

只加總帳本中已入帳（已付款）的贊助。待付款、待繳費、已過期、待人工處理、失敗與測試贊助都不算。

跑馬燈

純文字。可以放自訂句子，也可以接最近幾筆已付款贊助的名稱與金額。測試贊助不進跑馬燈。

Twitch 聊天

來源與顯示是兩個外掛。伺服器可以匿名讀取聊天室。選填的 Client ID 與 Client Secret 以密文保存，不會出現在 OBS 網址。聊天文字也不會被當成 HTML。

測試贊助會送到疊層並寫進事件紀錄，不建立訂單、不寫入帳本。YouTube 聊天來源還在路線圖上；事件形狀已預留，顯示外掛不必為了新來源改寫。把網址加進 OBS 的步驟見 登入、外掛與疊層。

簽過名的外掛市集

目錄來自與這個版本一起發布的官方索引。伺服器會再讀一次並檢查簽章，不會自動安裝。

Ed25519

官方索引已簽署。公鑰釘在程式裡，私鑰不在版本庫。沒有簽章、內容被改、或鑰匙不對，整份索引都不會被採用。

套件摘要

每份外掛有正規化 s4n-plugin.json 的 SHA-256。摘要和檔案不一致，就不會安裝或更新。

這個版本的界線

權限落在疊層與儀表板的社群外掛，最多只記下安裝狀態，不會執行它的程式，也不會出現在 OBS。

新安裝的外掛預設停用。密文欄位留在外掛頁，畫面只顯示已設定或未設定。細節見 外掛市集。

模組化單體

一個 API 程序承載帳本、認證、市集與即時事件。官方外掛與核心一起發布，功能從外面掛上。

使用者介面

  • apps/web 儀表板、贊助頁、外掛市集。Vite、React 19、Tocas UI。
  • apps/overlay OBS 瀏覽器來源，共用一張畫布。
  • apps/docs Starlight 文件，繁體中文。

核心 API

  • Hono：認證、帳本、外掛市集、密鑰密封。
  • 事件寫入 PostgreSQL，再用 LISTEN / NOTIFY 送出。
  • 斷線後依序號補齊。重複的事件 id 會被忽略。

外掛

  • 金流：綠界、歐付寶。僅官方，一種方式一個外掛。
  • 疊層：提醒、目標、跑馬燈、聊天顯示。
  • 連接器：Twitch 聊天來源。

正式環境由 Caddy 終止 TLS。儀表板與 API 同一個網域，OBS 疊層使用另一個主機名。PostgreSQL 不對外發布埠。映像在 GitHub Container Registry：

安全設計

完整說明、上線前檢查清單與回報方式不在本站重複。這裡只列公開文件已經寫明的界線。

主金鑰與密文

伺服器放一把 S4N_MASTER_KEY。外掛密鑰以 AES-256-GCM 密封，附加驗證資料綁定外掛與欄位，密文不能挪到別欄。全零的開發用金鑰在正式環境會拒絕啟動。

金流隔離

只有允許清單上的官方付款外掛能使用付款、密鑰與網路權限。入帳金額以伺服器訂單為準，不以廠商通知裡的金額覆寫。檢查碼以常數時間比對。

登入與疊層

密碼為 Argon2id。Cookie s4n_session 為 httpOnly、SameSite=Lax，正式環境加上 Secure。OBS 用另一組權杖，伺服器以 SHA-256 查找。

不可信內容

贊助人名稱、留言與聊天文字不以 HTML 解讀。提示音只接受經過 MIME 與檔頭檢查的音訊，路徑限制在音效目錄內。

部署面

API 與靜態服務以非 root 執行。正式 Compose 不發布資料庫或 API 埠，對外是 Caddy 的 80 與 443。

目前還沒有的

尚無內容安全政策。登入限流與 Twitch 徽章快取仍在單一程序的記憶體裡。多實例共用的登入限流在路線圖上。

若發現安全漏洞，請不要在公開 Issue 貼出可重現的利用細節。範圍與回報方式見 SECURITY.md。設計細節見 文件站的安全性。

AI 輔助開發。 S4N DONATE SYSTEM 2.0 有相當比例的程式碼與文件，是在維護者指導與審查下，藉由 AI 輔助開發工具產出。提交前經過人工檢視，但仍可能存在疏漏。請在用於正式環境前自行審查、測試，並依實際需求完成設定。本軟體依 MIT 授權現況提供，不對適用性或無錯誤作出保證。
