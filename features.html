核心特色與頁面架構

深入瞭解 S4N Donate System 如何整合金流、廣播通知與後台管理。

金流整合

多元第三方金流支援

完整對接 ECPay (綠界科技) 與 O'Pay (歐付寶) API。自動處理付款 Callback 機制與交易狀態驗證，確保每一筆贊助紀錄安全且無遺漏。

  • 支援信用卡、網路 ATM 與超商代碼繳費
  • 完整金流 Hash Key / Hash IV 加密傳輸處理
  • 自動判斷交易成功並觸發廣播通知
直播廣播

OBS 瀏覽器來源與動態廣播

實況主只需將 /obs 頁面新增至 OBS Studio 瀏覽器來源（Browser Source），當贊助交易完成時即可於直播畫面即時播放彈出通知。

  • 即時顯示贊助者暱稱、金額與留言內容
  • 自訂顯示秒數、動態特效與進場音效
  • 響應式透明背景設計，無縫融入直播畫面

系統頁面與路由對照表

頁面路徑 用途類型 詳細說明與技術機制
/
公開頁面 贊助填寫頁
觀眾進入填寫暱稱、贊助金額、留言並選擇金流支付方式，自動導向金流頁面。
/dashboard
管理頁面 實況主後台
查看詳細贊助歷史紀錄，線上即時設定廣播通知圖片、音效、字型、顯示時長與主題配色。
/obs
OBS 來源 廣播通知頁
透明背景設計，專門用於嵌入 OBS 瀏覽器來源。透過連線自動接收與輪播贊助通知。
/login
驗證頁面 管理員登入
提供 JWT 身分驗證與安全 Cookie 簽發，保護 /dashboard 後台不受未授權存取。
