部署步驟在文件站

這個網站只介紹產品。本機開發、正式環境與映像說明都寫在文件站，避免這裡的步驟和儲存庫不一致。

2.0 沒有 Zeabur 範本，也沒有一鍵代管。1.0 的部署方式已不適用。正式環境使用 Docker 映像、Caddy 與 PostgreSQL 16，映像發布在 GitHub Container Registry。

文件 本機開發 在自己的機器上把服務跑起來。 文件 正式環境 網域、Caddy、資料庫與備份。 文件 CI 與映像 GitHub Actions 與 GHCR 上的映像。 文件 上線前的安全檢查 主金鑰、埠與正式環境要核對的項目。

金流設定見 綠界與歐付寶。OBS 見 登入、外掛與疊層。原始碼在 GitHub。

AI 輔助開發。 S4N DONATE SYSTEM 2.0 有相當比例的程式碼與文件，是在維護者指導與審查下，藉由 AI 輔助開發工具產出。提交前經過人工檢視，但仍可能存在疏漏。請在用於正式環境前自行審查、測試，並依實際需求完成設定。本軟體依 MIT 授權現況提供，不對適用性或無錯誤作出保證。
