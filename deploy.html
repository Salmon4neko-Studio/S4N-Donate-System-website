系統部署指南

提供 Zeabur 雲端一鍵部署與 Docker Compose 伺服器快速建立方案。

最推薦

Zeabur 一鍵雲端部署

前往 Zeabur 範本部署 →
  1. 點擊上方的 前往 Zeabur 範本部署 按鈕跳轉至 Zeabur 主控台。
  2. Zeabur 將自動引導建立專案並配置獨立 PostgreSQL 資料庫。
  3. 在環境變數設定區域填寫必要變數（例如 ADMIN_USERNAME, ADMIN_PASSWORD, JWT_SECRET）。
  4. 點擊部署，完成後即可獲得免費授權的 HTTPS 子網域（例如 *.zeabur.app）。
自託管方案

Docker Compose 部署

官方 Docker Image: lokisalmonneko/s4n-donate-system:latest。在您的 VPS 伺服器建立 docker-compose.yml：

version: '3.8' services: app: image: lokisalmonneko/s4n-donate-system:latest ports: - "3000:3000" environment: - DATABASE_URL=postgresql://donate_user:secretpass@db:5432/donate_db - ADMIN_USERNAME=admin - ADMIN_PASSWORD=ChangeThisPassword123 - JWT_SECRET=SuperRandomSecretKey98765 - NEXT_PUBLIC_BASE_URL=https://your-domain.com depends_on: - db db: image: postgres:15-alpine environment: - POSTGRES_USER=donate_user - POSTGRES_PASSWORD=secretpass - POSTGRES_DB=donate_db volumes: - postgres_data:/var/lib/postgresql/data volumes: postgres_data:

啟動指令：

docker-compose up -d

🔧 環境變數說明

變數名稱 必填 說明 範例 / 預設值
DATABASE_URL 是 PostgreSQL 資料庫連線字串 postgresql://user:pass@db:5432/donate
ADMIN_USERNAME 是 後台管理員登入帳號 admin
ADMIN_PASSWORD 是 後台管理員登入密碼 password
JWT_SECRET 是 JWT 加密密鑰 (用於身分驗證) 請設定強隨機字串
NEXT_PUBLIC_BASE_URL 是 網站對外網址 (金流 callback 回調用) http://localhost:3000
ECPAY_MERCHANT_ID 否 綠界商店代號 2000132 (測試用代號)
ECPAY_HASH_KEY 否 綠界 Hash Key -
ECPAY_HASH_IV 否 綠界 Hash IV -
OPAY_MERCHANT_ID 否 歐付寶商店代號 -
OPAY_HASH_KEY 否 歐付寶 Hash Key -
OPAY_HASH_IV 否 歐付寶 Hash IV -
