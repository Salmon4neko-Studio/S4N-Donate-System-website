路線

做完了什麼，
還不做什麼

路線以公開儲存庫為準。沒有列在這裡的能力，就還沒有。

已完成

  • 模組化單體，以及簽過名的外掛市集
  • 營運者初次設定、登入，與伺服器端工作階段
  • 綠界與歐付寶的官方金流外掛
  • 帳本狀態，以及不進帳本的測試贊助
  • 贊助提醒、目標、跑馬燈、Twitch 聊天疊層
  • 以主金鑰密封外掛密鑰
  • PostgreSQL 事件紀錄，斷線依序號補齊
  • 正式環境的 Docker、Caddy 與 GHCR 映像

規劃中

  • YouTube 聊天來源。顯示外掛沿用同一份聊天事件，不必改寫。
  • 贊助頁自訂。版面與外觀還不能由營運者調整。
  • 多個 API 實例共用的登入限流。目前的計數在單一程序的記憶體裡。

已移除語音合成（TTS）已自這個版本移除，不會列入後續規劃。

常見問題

這是免費、可以自架的嗎？

是。S4N DONATE SYSTEM 2.0 以 MIT 授權發布，由你自己架設與維護。本站不提供代管，也沒有一鍵部署按鈕。

可以從 1.0 升級或搬資料嗎？

不行。2.0 是從零重寫，不是遷移。1.0 在 Zeabur 停止服務後已封存，舊的 Zeabur 範本、Docker Hub 映像與 GPLv3 說明都不再適用。

OBS 要加幾個瀏覽器來源？

一個。提醒、目標、跑馬燈與聊天顯示共用同一條網址、同一張畫布。網址從儀表板的疊層頁產生，正式環境的主機與儀表板分開。步驟見 登入、外掛與疊層。

可以同時用綠界和歐付寶嗎？

可以，但每一種付款方式都是獨立的官方外掛，要各自啟用、各自保存密文。目前列入官方索引的是綠界信用卡、ATM、超商代碼、超商條碼，以及歐付寶信用卡、ATM、超商代碼。歐付寶超商條碼尚未列入。

我可以自己寫一個付款外掛嗎？

這個版本不行。付款、密鑰與網路權限只給允許清單上的官方外掛。社群外掛若權限只落在疊層與儀表板，最多記下安裝狀態，程式不會被執行。

有語音，或目標會把測試贊助算進去嗎？

沒有語音合成。目標只計算已入帳的贊助。測試贊助會出現在提醒疊層，不寫入帳本，也不進目標或跑馬燈。

文件是哪一種語言？部署教學在哪？

文件以繁體中文撰寫，站點是 docs.donate-system.salmon4neko.com。本機開發、正式環境與映像說明都在那裡。本站的 自架頁只放連結，不附步驟。
