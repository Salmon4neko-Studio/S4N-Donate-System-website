常見問題 (FAQ)

S4N Donate System 是免費且開源的嗎？
是的，S4N Donate System 是一款 100% 免費且開源的實況主贊助平台，採用 GNU General Public License v3.0 (GPLv3) 授權發布。您可以自由下載、部署、修改原始碼。
如何在 OBS Studio 中加入贊助通知廣播？
在 OBS Studio 的「來源」區塊點擊新增「瀏覽器 (Browser)」，將 URL 設定為您的部署網址加上 /obs (例如 https://your-domain.zeabur.app/obs)，並將寬度設定為 1920、高度設定為 1080 即可。當有觀眾進行贊助時，通知將會自動以透明背景彈出播放。
我可以同時使用綠界 (ECPay) 與歐付寶 (O'Pay) 嗎？
可以！系統支援填寫綠界或歐付寶的商店 API 憑證。在公開贊助頁面中，觀眾可以自由選擇習慣的金流管道進行線上支付。
我完全沒有維護 PostgreSQL 資料庫經驗，該如何處理？
極力推薦使用 Zeabur 部署範本。Zeabur 會自動為您佈建全託管的 PostgreSQL 資料庫並完成連線，免去繁瑣的 SQL 設定與資料庫維護。
如何修改廣播動畫的音效或顯示秒數？
請造訪 /login 輸入設定的管理者憑證進入 /dashboard 後台。在後台設定選單中即可線上記時修改彈出時間、廣播圖示、字型與提示音效。
